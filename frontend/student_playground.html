Access Granted

Step-by-Step Guide:

1. Drag an IF-ELSE block from the Logic category.
2. Drag a COMPARE block into the IF condition.
3. Set the comparison as follows:
   • Left Number: 85
   • Operator: GTE (>=)
   • Right Number: 80
4. Inside the IF (DO) section, add a PRINT block with the text "Access Granted"
5. Inside the ELSE section, add a PRINT block with the text "Access Denied"
6. Click RUN CODE to execute the program.

Expected Output: "Access Granted"
