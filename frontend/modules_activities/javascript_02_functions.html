Lesson Content

4.1 What is a Function?

A function is a reusable block of code. Instead of writing the same code again and again, you define a function once and call it whenever you need it.

Think of it like a recipe: you write down the steps once, then "run" the recipe whenever you want the result.

4.2 Defining a Function

In JavaScript, you define a function with the function keyword:

JavaScript 
function greet() {
    console.log("Hello!");
}

This code does not run by itself — you need to call the function.

Syntax rules:

  • Start with the function keyword.
  • Function name — camelCase convention (e.g., sayHello).
  • Empty parentheses () for parameters (see 4.3).
  • Curly braces { } wrap the body.
  • No semicolon after the closing }.

4.3 Calling a Function

To run the function, write its name followed by parentheses:

JavaScript 
function greet() {
    console.log("Hello!");
}

greet();   // call the function
greet();   // call it again
OutputHello! Hello!

4.4 Parameters (Passing Data In)

Parameters let you pass data into a function. You list them inside the parentheses when defining, and pass values when calling:

JavaScript 
function greet(name) {
    console.log("Hello, " + name + "!");
}

greet("Anna");    // pass "Anna"
greet("Caryll");  // pass "Caryll"
OutputHello, Anna! Hello, Caryll!

Key terms:

  • Parameter — the variable in the function definition (e.g., name).
  • Argument — the actual value you pass when calling (e.g., "Anna").

4.5 Return Values

Use return to send a value back from the function. This lets you store or reuse the result:

JavaScript 
function add(a, b) {
    return a + b;
}

let result = add(5, 10);
console.log(result);   // prints 15
console.log(add(3, 7));   // prints 10
Output15 10

Rules:

  • return immediately ends the function.
  • Any code after return will not run.
  • If a function has no return, it returns undefined.

4.6 Combining Functions with Variables

Functions can use any of the concepts from Module 1 — variables, math, if-statements, loops:

JavaScript 
function checkPass(score) {
    if (score >= 75) {
        return "Passed";
    } else {
        return "Failed";
    }
}

console.log(checkPass(85));   // Passed
console.log(checkPass(60));   // Failed
OutputPassed Failed
Section 5

Worked Example

Let's build a small function step by step.

Goal

Create a function that calculates the total price given a quantity and price per item.

Complete Code

JavaScript 
function totalPrice(qty, price) {
    return qty * price;
}

console.log(totalPrice(3, 50));    // 150
console.log(totalPrice(10, 5));   // 50
Output150 50

Step-by-Step

  1. 1
    Declare the function

    function totalPrice(qty, price) { ... }

  2. 2
    Two parameters

    qty and price receive the arguments.

  3. 3
    Return the product

    return qty * price; sends the result back.

  4. 4
    Call with different values

    totalPrice(3, 50) → 150. totalPrice(10, 5) → 50.

Matching Blockly Blocks

function totalPrice(qty, price) → return qty * price → console.log(totalPrice(3, 50))
