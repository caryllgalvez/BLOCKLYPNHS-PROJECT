1. The Python for loop

A Python for loop repeats a block of code for each value produced by range(). The body must be indented (usually 4 spaces). 

main.pyfor i in range(1, 6):
    print(i)
Output1 2 3 4 5
  • range(1, 6) produces 1, 2, 3, 4, 5 — the stop value 6 is not included.
  • print(i) is indented → it belongs to the loop body.
  • Each iteration, i takes the next value from range().

2. The Python while loop

A while loop runs while its condition is True. You must update the loop variable inside the body, or the loop will never end. 

main.pyi = 1
while i <= 5:
    print(i)
    i = i + 1
Output1 2 3 4 5
Watch out: If you forget i = i + 1, the condition stays True forever — that's an infinite loop.

3. for vs while — which one?

  • Use for when you know how many times to repeat (e.g., 1 to 5).
  • Use while when repetition depends on a condition that may change.

4. Python indentation

Python uses indentation instead of { } braces to define what is inside the loop. If a line is not indented, it runs after the loop finishes. 

main.pyfor i in range(1, 4):
    print("inside")
print("after")
Outputinside inside inside after

Worked Example

Trace the loop variable step by step to understand the output.

Task: Print the numbers 1 to 5 using a Python for loop. 

main.pyfor i in range(1, 6):
    print(i)
Expected Output1 2 3 4 5

Step-by-step trace

  1. range(1, 6) produces the sequence 1, 2, 3, 4, 5.
  2. Iteration 1: i = 1 → print 1.
  3. Iteration 2: i = 2 → print 2.
  4. Iteration 3: i = 3 → print 3.
  5. Iteration 4: i = 4 → print 4.
  6. Iteration 5: i = 5 → print 5.
  7. No more values → loop ends.
Matching Blockly block: for i from 1 to 5 step 1 do … with a print (i) inside the body.
