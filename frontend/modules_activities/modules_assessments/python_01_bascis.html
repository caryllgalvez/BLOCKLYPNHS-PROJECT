1. Printing in Python

Python uses the built-in print() function to display output. Text goes inside double (or single) quotes. Python does not require a semicolon at the end of a line. 

main.pyprint("Hello, Python!")
OutputHello, Python!
print() automatically adds a new line after its output. No semicolon needed — Python uses indentation and newlines instead.

2. Python variables don't need a type

In Python you just write name = value. The type is inferred automatically from the value. 

main.pyage = 16              # int
price = 19.99         # float
name = "Alice"        # str
is_student = True     # bool
Common mistake: Don't write int age = 16 in Python — that's Java/C++ syntax. Python just uses age = 16.

3. Printing a variable

Put the variable name (no quotes) inside print() to print its value: 

main.pyage = 16
print(age)   # prints 16, not "age"
Output16
