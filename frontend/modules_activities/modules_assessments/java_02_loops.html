Lesson Content

Read carefully — the quiz and final assessment test exactly these concepts.

1. The Java for loop

A for loop repeats a block of code a fixed number of times. It has three parts separated by semicolons inside the parentheses: 

Main.javafor (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
Output1 2 3 4 5
  • Initialization — int i = 1 runs once at the start.
  • Condition — i <= 5 is checked before every iteration. If false, the loop ends.
  • Update — i++ runs after the body. It increases i by 1.

2. The Java while loop

A while loop is used when you don't know in advance how many times to repeat — it just keeps going while its condition is true. 

Main.javaint i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}
Output1 2 3 4 5
Watch out: If you forget i++ inside a while loop, the condition stays true forever — that's an infinite loop.

3. for vs while — which one?

  • Use for when you know how many times to repeat (e.g., 1 to 5).
  • Use while when repetition depends on a condition that may change (e.g., until the user types "quit").

Worked Example

Trace the loop variable step by step to understand the output.

Task: Print the numbers 1 to 5 using a Java for loop. 

Main.javafor (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
Expected Output1 2 3 4 5

Step-by-step trace

  1. int i = 1 → i is 1.
  2. Check i <= 5 → 1 ≤ 5 is true. Print 1. Then i++ → i is 2.
  3. Check i <= 5 → 2 ≤ 5 is true. Print 2. Then i is 3.
  4. Print 3, i becomes 4.
  5. Print 4, i becomes 5.
  6. Print 5, i becomes 6.
  7. Check i <= 5 → 6 ≤ 5 is false. Loop ends.
Matching Blockly block: for (int i = 1; i <= 5; i++) with a System.out.println + GET VARIABLE (i) inside the body.
