Lesson Content

4.1 What is C++?

C++ is a compiled, high-performance programming language created by Bjarne Stroustrup. It's used for games, operating systems, and applications where speed matters.

A C++ program starts from a main() function and includes libraries at the top:

C++ 
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!";
    return 0;
}
OutputHello, World!

4.2 Output with cout

In C++, cout prints to the console. Note the insertion operator << (two less-than signs) — this is not PHP's echo or JS's console.log().

C++ 
cout << "Hello, C++!";
OutputHello, C++!

Rules:

  • Every statement ends with a semicolon ;.
  • Text goes inside double quotes "...".
  • C++ is case-sensitive — cout works, Cout doesn't.
  • No automatic newline — use endl or "\n" for a line break.

4.3 Variables — Typed Declarations

Unlike PHP and JavaScript, C++ requires you to declare the type of each variable:

C++ 
int age = 17;           // whole number
double gpa = 95.5;      // decimal number
string name = "Anna";    // text
bool passed = true;      // true / false

cout << name;            // prints Anna
OutputAnna

Common C++ types:

  • int — whole numbers (e.g., 17, -5, 0)
  • double — decimal numbers (e.g., 95.5, 3.14)
  • string — text (needs #include <string>)
  • bool — true or false

Naming rules: start with a letter or _, case-sensitive, no spaces, can't be a reserved keyword.

4.4 Math Operations

Same operators as other languages: +, -, *, /.

C++ 
cout << 6 * 5;    // multiply
cout << 80 - 50;   // subtract
cout << 10 + 3;    // add
Output30 30 13

4.5 Comparisons at if Statements

Use >, <, ==, !=. Same as other languages — but remember == for comparison, = for assignment.

C++ 
if (15 < 20) {
    cout << "15 is less than 20";
}
Output15 is less than 20

4.6 For Loops

The for loop repeats code — the counter's type must be declared too.

C++ 
for (int i = 1; i <= 5; i++) {
    cout << i << endl;
}
Output1 2 3 4 5
Section 5

Worked Example

Let's build a small C++ script step by step.

Goal

Store a student's name and age in variables, then print them in a sentence.

Complete Code

C++ 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Anna";
    int age = 16;

    cout << "Name: " << name << " | Age: " << age;

    return 0;
}
OutputName: Anna | Age: 16

Step-by-Step

  1. 1
    Include libraries

    #include <iostream> for cout, #include <string> for string.

  2. 2
    Declare typed variables

    string name and int age.

  3. 3
    Chain with <<

    Each << sends the next piece to cout.

  4. 4
    Return 0

    Every main() should end with return 0;.

Matching Blockly Blocks

string name = "Anna" → int age = 16 → cout << "Name: " << name << ...
