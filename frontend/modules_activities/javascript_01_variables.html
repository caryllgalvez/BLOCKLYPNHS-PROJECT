4.1 What is JavaScript?

JavaScript is a client-side scripting language â€” it runs in the browser, not on the server. It makes web pages interactive. Every modern browser can run JavaScript.

You write JavaScript in a <script> tag or a .js file. Here's the basic structure:

JavaScript 
// This is a comment
console.log("Hello, World!");
OutputHello, World!

4.2 Output with console.log()

console.log() prints text to the browser's developer console. It's the JS equivalent of PHP's echo.

JavaScript 
console.log("Hello, World!");
OutputHello, World!

Rules:

  • Every statement ends with a semicolon ; (though JS is forgiving).
  • Text must be wrapped in quotes â€” single '...' or double "...".
  • JavaScript is case-sensitive â€” console.log works, Console.Log doesn't.

4.3 Variables â€” let at const

In modern JavaScript, you declare variables using let (can be changed) or const (cannot be changed). No $ symbol â€” that's PHP!

JavaScript

let age  = 16;          // number
const grade = 11;      // constant
console.log(name);      // prints Anna
OutputAnna

Rules:

  • No $ prefix â€” that's PHP only.
  • Must start with a letter, _, or $ (but $ is discouraged in modern JS).
  • Case-sensitive: name â‰  Name.
  • Cannot start with a number.

4.4 Math Operations

JavaScript uses +, -, *, / â€” same as PHP.

JavaScript 
console.log(25 + 15);   // add
console.log(80 - 50);   // subtract
console.log(10 * 3);    // multiply
Output40 30 30

4.5 Comparisons at if Statements

JavaScript uses the same comparison operators as PHP: >, <, ==, !=. Combine with if.

JavaScript 
if (20 > 10) {
    console.log("20 is greater than 10");
}
Output20 is greater than 10

4.6 For Loops

The for loop repeats code a set number of times. Modern JS uses let in the loop header.

JavaScript 
for (let i = 0; i <= 4; i++) {
    console.log("I love programming!");
}
OutputI love programming! I love programming! I love programming! I love programming! I love programming!
