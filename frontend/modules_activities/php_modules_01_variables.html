Lesson Content

4.1 What is PHP?

PHP stands for PHP: Hypertext Preprocessor. It's a server-side scripting language — the code runs on the web server, not the browser. PHP files end with .php and PHP code lives inside <?php ?> tags.

PHP 
<?php
    echo "Hello, World!";
?>
OutputHello, World!

4.2 Variables

In PHP, every variable starts with the $ sign. You don't need to declare the type — PHP figures it out.

PHP 
<?php
    $name = "Anna";   // string
    $age  = 16;       // integer
    echo $name;
?>
OutputAnna

Rules: must start with $, then a letter or underscore. Case-sensitive. No need to declare type.

4.3 Math Operations

PHP supports arithmetic with +, -, *, /.

PHP 
<?php
    echo 80 - 50;   // subtract
    echo 10 * 3;    // multiply
?>
Output30 30

4.4 Comparisons & If Statements

Use >, <, ==, != to compare. Combine with if to decide what to do.

PHP 
<?php
    if (25 > 18) {
        echo "25 is greater than 18";
    }
?>
Output25 is greater than 18

4.5 For Loops

A for loop repeats code a set number of times.

PHP 
<?php
    for ($i = 0; $i < 3; $i++) {
        echo "Learning PHP!";
    }
?>
OutputLearning PHP! Learning PHP! Learning PHP!
Section 5

Worked Example

Let's build a small script step by step.

Goal

Store a student's name and age in variables, then print them in a sentence.

Complete Code

PHP 
<?php
    $name = "Anna";
    $age  = 16;
    echo "My name is " . $name . " and I am " . $age;
?>
OutputMy name is Anna and I am 16

Step-by-Step

  1. 1
    Declare $name

    Store the string "Anna" in $name.

  2. 2
    Declare $age

    Store the number 16 in $age.

  3. 3
    Concatenate with echo

    Use the dot . to join strings and variables.

  4. 4
    Output

    echo prints the result.
